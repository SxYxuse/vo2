# A goal's priority replaces its objective

Supersedes the objective in [0026](0026-the-week-is-planned-upfront-from-a-plan-built-on-the-season.md) and, for goals, "every goal is perform" in [0037](0037-the-coach-plan-is-written-by-the-coach-inside-a-budget-vo2-sets.md).

A goal had two choices: a priority (A, B, or C) and an objective (finish, finish well, or perform). The two said nearly the same thing, athletes rarely picked a mix that changed the plan, and the coach plan already hid the objective. A goal now has only a priority, and it carries what the objective did: an A race is to perform, a B race to finish well, and a C race to finish.

The week planner reads the priority wherever it read the objective: how fast fitness rises and which key sessions lead toward the goal the plan builds to, how many key sessions a week (three for A, two for B, one for C), and the easy days and opener around a goal. Each keeps the values the matching objective had. A B goal raced to perform, which took its whole week down a notch, no longer exists, and a C goal no longer gets easy days around it.

Keeping the objective as a column set from the priority was the alternative. It would have stored a second name for the priority and left most of the planner's rules unreachable, so the column is dropped. A copied season that still carries an objective is read without it.
