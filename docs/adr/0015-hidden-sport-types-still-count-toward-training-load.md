# Hidden sport types still count toward training load, fitness, fatigue, and form

Hiding a sport type in Settings → Sports changes what is shown, not what the body did. Its activities stay out of the calendar, map, and heart-rate views, but they still add training load and move fitness, fatigue, and form, and they still feed the load anchors (FTP, LTHR, resting HR) behind that load.

Athletes hide a type to declutter, typically walks or commutes. That work still tires them and still builds fitness. Dropping it from the PMC would make form read fresher than the athlete is, and the remaining-week plan would ask for more than they can absorb.

The trade-off is that form can move on a day where the calendar shows nothing. That is preferred to a fitness curve that changes when a display setting does.
