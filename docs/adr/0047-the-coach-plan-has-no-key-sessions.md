# The coach plan has no key sessions

The coach plan marked the long run and the quality sessions as key: the writer set a `key` flag, the week strip drew those runs darker, the day and the session page showed a Key badge, a plan change said "key", and a missed key session wrote the weeks ahead again ([0037](0037-the-coach-plan-is-written-by-the-coach-inside-a-budget-vo2-sets.md), [0040](0040-the-coach-plan-is-written-when-the-app-asks-and-short-weeks-allow-a-bigger-long-run-share.md)).

Now a run is a run. The athlete sees its title, distance, and whether it was done or missed. The writer no longer fills in `key`, and missing a run, of any kind, no longer starts a writing: a missed session is skipped (rule 8), so the days after it don't need writing again. Availability, goals, paces, a new week, switching back to the coach plan, and Try again still write.

The quality-session cap, the long run, and hard days stay rules the plan is checked against: they limit the week, they are not a kind of session to label.

Plans already stored keep `key` on their runs; VO2 reads them without it and does not write a plan again to drop it. The week planner keeps its key sessions, unchanged.

This supersedes, for the coach plan, the rewrite after a missed key session in 0037 and 0040.
