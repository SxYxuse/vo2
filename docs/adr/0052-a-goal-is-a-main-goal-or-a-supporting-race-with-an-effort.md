# A goal is a main goal or a supporting race with an effort

Supersedes [0024](0024-goal-priority-guardrails-and-week-coach.md) and [0049](0049-a-goals-priority-replaces-its-objective.md) for what a goal's priority means and how it shapes the plan. A goal is either a main goal (A) raced to perform, or a supporting race (B) run at an effort: fun, steady (70–80 %), or all out. The C letter goes away, since its "trained through" rule contradicted the easy "fun" copy and the running doc's rule that every race replaces a quality session. Existing C goals become B with fun, and existing B goals become B with steady. We follow Runna's model of a main race with supporting races and their three efforts, so the athlete's expectations match the app they already use. Runna allows one main race per plan; we keep several main goals, since the season is a list of dated goals, each with its own build, taper, and recovery.

A supporting race never leads the season: with no main goal ahead, the plan holds fitness. Fun has minimal impact and counts as the week's easy run. Steady keeps the week's other runs easy, trims race week to 85 % load, and makes the next week lighter. All out gets the main race's taper and a recovery week, with no build ramp. Adding a supporting race is blocked only when it falls inside the main race's taper. Runna's other limits (shorter than the main race, timing, no hard efforts within 7–10 days, no back-to-back races) were dropped on purpose.
