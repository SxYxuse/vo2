# Locomotion display follows sport group, not an athlete preference

Completed-work locomotion is shown in the language of the sport group: pace (min/km) for running and walking, pace (min/100m) for swimming, speed (km/h) for cycling and everything else. There is no athlete toggle.

A settings row would default to this convention anyway. The switch people actually ask for is imperial, which VO2 is not adding. km/h on a run and min/km on a ride are not how those sports are coached, and analysis already talks to sport groups.
