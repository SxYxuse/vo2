# The coach plan takes changes only from the coach chat

Supersedes the coach notes part of [0038](0038-the-coach-chat-can-propose-plan-changes-the-athlete-applies.md): the quick choices and the athlete's own words sent from a week of the plan, and the note's dialog on Plan. The coach chat's plan changes stay as 0038 describes them.

Coach notes asked for a change from a second place with its own choices and its own dialog, so the same change could be asked for in two ways. The coach chat already reads the plan and proposes a change the athlete applies, so Plan keeps one way in: its "Ask the coach to change my plan" button opens the chat. The note's quick choices and their message go, with the reply dialog only notes used.
