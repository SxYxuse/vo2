# Without a main goal, the coach plan builds base fitness

Supersedes, in part, [0052](0052-a-goal-is-a-main-goal-or-a-supporting-race-with-an-effort.md): with no main goal ahead, the season no longer holds fitness, it builds base fitness.

The coach plan no longer needs an A goal. An athlete with no main goal ahead, whether they never set one or their last one is behind them, gets a plan like any other: the weeks are base weeks, every fourth one lighter at 70 %, counted on the calendar since there is no goal to count back from. Every planned sport grows at Standard by default (or the progression the athlete set) up to the peak ceiling VO2 recommends without a goal in the sport ([0058](0058-each-sports-budget-grows-at-a-progression-the-athlete-sets-up-to-a-peak-ceiling.md)), and then holds there. The two weeks after a main goal still don't ramp: recovery, then maintain, then base. Supporting races still never lead the season; they change only the weeks around them, by their effort, as before. Plan shows the next twelve weeks of the season when no main goal is ahead, or through the last supporting race if it's later. Onboarding's A race step can be continued without a race.

Athletes without a race were left with no plan at all, which is the moment a coach is most useful: between seasons, or before they have picked a race. Holding fitness flat for them meant the plan never moved; base fitness is what coaching advice prescribes without a target (mostly easy volume and a growing long session), and the no-goal ceiling already stops it from growing without end.

## Considered options

- **Keep requiring an A goal:** athletes without a race get nothing.
- **Hold fitness without a goal:** the weeks never grow, so the plan is the same week forever.
- **Ask the athlete for a "base" pseudo-goal with a date:** a fake race to count back from adds a setting nobody would understand.
