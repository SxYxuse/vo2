# Activities are read in the coach chat, not in a saved analysis

The activity page no longer has an AI analysis card. Its **Ask about this activity** button opens the coach chat with that activity brought in, and the athlete asks what they want to know there. Saved analyses are dropped, along with their table and the activity analysis model choice in Settings → Coach. This changes the coach features named in ADR 0036 to coach notes, coach chat, and plan writing.

The coach chat reads the same overview, climbs, stream correlations, and effort phases the analysis did, and it can follow up, compare with other sessions, and propose plan changes. A one-shot write-up next to it was a second way to pay for the same reading, with its own model setting, endpoint, and table, and it answered a question the athlete had not asked.
